# One Shirt, Many Meanings

## A Mini Textbook on Persuasion, Identity, and Visual Form

This guide uses the plain white T-shirt as a recurring object for studying how meaning is built. Across five chapters, it connects persuasion, brand archetypes, visual design, and AI-assisted creative work. The goal is not to find one correct interpretation. It is to learn how to make choices, explain them, and review their consequences.

## How to Use This Guide

Read Chapters 1–3 as three complementary lenses. Use Chapter 4 to see those lenses applied to one familiar object, then use Chapter 5 to turn creative intent into a bounded, reviewable workflow for AI-assisted work.

As you read, separate documented facts from interpretation. Answer the questions at the end of each chapter, test your ideas against the comparison tables and diagrams, and revisit an earlier chapter when a later example raises a new question. The Mermaid diagrams require a Markdown viewer that supports Mermaid.
